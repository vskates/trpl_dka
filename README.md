# Построение ДКА по регулярному выражению
Реализован на основе алгоритма Глушкова.
## Пайплайн алгоритма:

1. разбирает регулярное выражение;
2. линеаризует его, нумеруя все вхождения символов;
3. вычисляет множества nullable, firstpos, lastpos, followpos;
4. строит ДКА;
5. генерит `.tex`-файл с описанием состояний, переходов и диаграммой автомата.

## синтаксис

- `a`, `b`, `c`, ..., `z`, `A`...`Z`, цифры `2`...`9` - обычные символы алфавита;
- `ab` - конкатенация;
- `a|b` - альтернатива;
- `a*` - звезда Клини;
- `( ... )` - скобки;
- `1` - пустое слово;
- `0` - пустой язык.

пример
```text
(a|b)*abb
```

## файлы:

- `Main.hs` - запускать отсюда
- `Regex.hs` - типы для регулярных выражений и еще разметка позиций
- `RegexParser.hs` - это парсер
- `Glushkov.hs` - вычисление `firstpos/lastpos/followpos` и построение ДКА
- `Latex.hs` - генерация latex, TikZ;
- `report/report.tex` - описание

## собирать так:

Я проверяла код с такими версиями:

- `ghc 9.4.7`
- `cabal-install 3.8.1.0`

```bash
ghc --make Main.hs -o dka
```

## запускать так:

```bash
./dka
```

Если передавать кастомное регулярное выражение и имя выходного файла:

```bash
./dka "(a|b)*abb" -o example.tex
```

после запуска программа делается print промежуточных множеств и переходы в терминал + сохраняется latex файл, который можно компилировать в pdf.

## сборка pdf с диаграммой

```bash
pdflatex example.tex
```

## сборка отчёта

```bash
cd report
pdflatex report.tex
```

## Проверенные мной примеры

- `(a|b)*abb`
- `a(b|c)*`
- `(ab|ba)*`
- `1|ab`

При проверке имеет смысл смотреть на:

1. корректность множеств `FirstPos`, `LastPos`, `FollowPos`;
2. принимающие состояния;
3. совпадение меток на переходах с символами из позиций.
